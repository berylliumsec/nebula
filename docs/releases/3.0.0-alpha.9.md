# Nebula 3.0.0-alpha.9

Nebula 3.0.0-alpha.9 turns the Code and Browser views into durable security
research workbenches and improves continuity across Assistant and the rest of a
Project. The release keeps Terminal, agents, reviewed execution, Evidence, and
Findings as their existing authorities instead of duplicating them inside the
editor or browser.

## Changes since alpha.8

- Code now provides practical everyday VS Code capability coverage with
  CodeMirror 6: multi-file and split editing, quick open, bounded workspace
  search, conflict-aware saves, recoverable hot exit, configurable keybindings,
  and responsive desktop and mobile layouts.
- Python editing adds completion, hover, signatures, open-buffer definition and
  references, rename, Ruff formatting, and live Problems through an ephemeral,
  authenticated language session that does not execute project configuration.
- Code shows hardened Git status and staged or working diffs, discovers common
  test and task entry points, and safely reads supported `tasks.json` and
  `launch.json` profiles. Commands still enter Nebula's existing reviewed
  execution flow rather than running implicitly.
- Saved Python files can be debugged with debugpy through the Debug Adapter
  Protocol. Breakpoints, stepping, stack frames, variables, evaluation, and
  restart run against the exact saved hash in a read-only, network-disabled,
  time-bounded Kali session.
- Editor actions hand exact workspace paths and hashes to Terminal, Assistant,
  immutable Evidence, and operator-reviewed candidate Findings. The toolbar now
  remains readable without overlapping controls at compact widths.
- Browser research now has durable sessions, tabs, identities, navigation
  timelines, redacted HTTP/1.1 and HTTP/2 history, WebSocket metadata, reviewed
  replay, two-identity authorization comparison, Project CA lifecycle, DevTools,
  semantic page Evidence, and scope-bound AI action proposals that require
  one-shot operator approval.
- Browser scope and identity state survive refresh and reconnect. Paired clients
  can inspect durable state and queue expiring navigation handoffs without
  receiving live cookies or implicit desktop control.
- Assistant preserves unsent per-conversation drafts, supports bounded exact
  multi-source context packs and image input, exposes Core-owned context health,
  and adds copy, quote, fork, search, and authoritative transcript export without
  creating a second agent or transcript authority.

This candidate adds database migrations for durable browser research state and
workspace/editor capabilities. The migrations preserve existing Project,
engagement, conversation, Evidence, Finding, and Report records.

## Native packages

The release workflow stages the following artifacts for manual review:

- a Linux x86_64 AppImage for direct distribution; and
- a Linux x86_64 DEB for managed distribution.

Direct builds can consume Nebula's signed updater channel. Managed builds omit
the direct updater so deployment remains under administrator control. macOS,
Windows, Linux arm64, RPM, Flatpak, Snap, and Homebrew artifacts are not included
in this alpha.

The packaged desktop includes the Chromium runtime required for rendered URL
sources. Docker or Podman is required for terminal, automation, and isolated
debugger features. A model provider or supported assistant harness remains
optional; Code, the human terminal, browser inspection, evidence workflows,
notes, findings, and reports remain usable without one.

## Deliberate boundaries and alpha limitations

- This is a prerelease and may contain compatibility defects or incomplete UX.
- Code does not host an extension marketplace or duplicate Terminal, agents,
  approvals, containers, Evidence, or Findings. Python language intelligence is
  deliberately bounded to editor-supplied open buffers; extension-owned task
  types and debug profiles remain visible but disabled.
- Browser capture does not yet claim pixel screenshots, raw body-artifact
  capture, live pause-and-modify interception, upstream-proxy chaining, or
  browser-extension hosting. Page capture is semantic Evidence and is not
  presented as a screenshot.
- Engagement bundle export is integrity-manifested, but this alpha does not yet
  provide a bundle restore path.
- Terminal, automation, debugging, and task execution depend on a compatible
  local container runtime and its networking configuration.
- Physical iPhone Safari remains a manual release-verification gate; automated
  mobile WebKit and non-loopback LAN coverage do not replace it.

## After installation

Launch the desktop with `nebula`. Confirm the bundled Core, browser runtime, and
local execution boundary before beginning an engagement:

```console
nebula-core doctor --json
```

Report defects with the exact version, platform, failed action, correlation ID,
and a Diagnostics support bundle after reviewing it for sensitive engagement
data.
