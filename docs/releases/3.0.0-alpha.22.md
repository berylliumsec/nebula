# Nebula 3.0.0-alpha.22

This Linux desktop prerelease includes the changes merged into main through
`5c567ca` (September 27, 2026), following the unpublished alpha.21 candidate.

## Changes since alpha.21

- Conversation context now uses structured memory, incremental and background
  compaction, bounded tool receipts, and on-demand archived conversation search.
- Project knowledge is selected for relevance and cited alongside the answer,
  including knowledge retrieved during harness turns. The Knowledge banner shows
  local relevance-model download progress and failures.
- Working context shows calibrated usage, memory, partial summaries, and agent
  notes. Provider accounting distinguishes cache reads and writes and prefers
  reported billed cost.
- Operator help follows the question being asked, and failure questions can
  retrieve the relevant runbook and searchable failure receipts.
- Conversation actions and selected browser journeys receive regression fixes.

The [source comparison](https://github.com/berylliumsec/nebula/compare/nebula-v3.0.0-alpha.21...nebula-v3.0.0-alpha.22)
contains the full change history. These highlights describe merged changes;
manual verification limitations below remain applicable.

## Native packages

The release workflow builds Linux x86_64 AppImage and DEB packages only.
The desktop bundles Chromium for rendered URL sources and managed browsing.
Docker or Podman is required for container execution and related isolated tools.

## Alpha limitations

This prerelease may contain compatibility defects or incomplete workflows.
Host mode executes authorized commands on the Nebula host; select Host or Docker
execution deliberately. Managed browsing can act on authenticated web sessions.
VPN routing applies to selected container workloads, not the host or browser device.
Physical iPhone Safari, physical macOS remote-Core, provider-diverse, and
authenticated-browser workflows remain manual verification gates.

## After installation

Launch the desktop with `nebula`, then run `nebula-core doctor --json`.
Create or select a project, choose the execution mode, and open Assistant.
Report defects with the version, platform, failed action, correlation ID, and a
reviewed Diagnostics support bundle.
