# Nebula 3.0.0-beta.1

This Linux desktop beta follows the published alpha.5. Alpha.6 through
alpha.22 were development candidates and were not published. The
[source comparison](https://github.com/BerylliumSec/nebula/compare/nebula-v3.0.0-alpha.5...nebula-v3.0.0-beta.1)
contains the complete change history.

## Highlights since alpha.5

- Assistant conversations gained durable turn and activity records, recovery
  for interrupted work, subagents, side chats, and faster navigation through
  long histories.
- Provider, harness, and project settings gained model discovery, permission
  controls, clearer failures, and project-scoped defaults.
- The desktop and phone workspaces gained editor, terminal, browser, search,
  navigation, and accessibility improvements.
- Project Work now brings agent activity, assignments, and check-ins into a
  project overview with links back to the associated conversations.
- The public website now leads to the signed Nebula APT installation page.
  Direct AppImage downloads remain available from this release.

## Native packages

The protected workflow produces a Linux x86_64 AppImage for direct distribution
and a Linux x86_64 DEB for managed distribution. It does not build macOS,
Windows, Linux arm64, RPM, Flatpak, Snap, Homebrew, or browser-extension
artifacts. The desktop bundles Chromium for rendered URL sources and managed
browsing. Docker or Podman is required for container execution and related
isolated tools.

## Beta limitations

- This beta is not a stable release and may contain compatibility defects or
  incomplete workflows.
- Host mode runs authorized commands on the Nebula host; Docker mode uses the
  configured container boundary. Select the execution mode deliberately.
- Managed browser control can act on authenticated web sessions. Review the
  visible page and stop browser control when it is no longer required.
- VPN routing applies to selected container workloads, not the host or browser
  device.
- Physical iPhone Safari, physical macOS remote-Core, provider-diverse, and
  authenticated-browser workflows remain manual verification gates.

## After installation

Launch the desktop with `nebula`, then run `nebula-core doctor --json`.
Create or select a project, choose the execution mode, and open Assistant.
Report defects with the version, platform, failed action, correlation ID, and
a reviewed Diagnostics support bundle.
