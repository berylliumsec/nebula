# Nebula 3.0.0-beta.3

This Linux desktop beta is the next release candidate after beta.2. Beta.2 was
tagged for preparation but was not published. The [source comparison](https://github.com/BerylliumSec/nebula/compare/nebula-v3.0.0-beta.2...nebula-v3.0.0-beta.3)
contains the complete change history.

## Changes since beta.2

- Harness conversations now report the provider subagent selection from their
  actual provider configuration, while command runtime selection remains
  independent.
- Harness knowledge tools now respect the active turn's access scope.
- Release preparation and draft creation verify the initiating repository
  admin's permission before using release credentials.

## Packages and limitations

The release workflow builds Linux x86_64 AppImage and DEB packages. The DEB is
intended for the prerelease APT channel after its separate promotion checks.
This beta is not a stable release. Docker or Podman remains necessary for
container execution and related isolated tools. Host mode runs authorized
commands on the Nebula host. Physical iPhone Safari, physical macOS
remote-Core, provider-diverse, and authenticated-browser workflows remain
manual verification gates.

After installation, launch the desktop with `nebula` and run
`nebula-core doctor --json`.
