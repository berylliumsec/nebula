# Nebula 3.0.0-alpha.12

Nebula 3.0.0-alpha.12 supersedes the unpublished alpha.11 candidate. It carries
the OpenVPN container-egress, authoritative harness-runtime, resource, search,
conversation, settings, and Security Browser changes documented in the
[alpha.11 notes](3.0.0-alpha.11.md), plus a corrected Linux release gate.

## Changes since alpha.11

- The protected release workflow now exercises container workloads through
  Nebula's admitted local rootless Podman CLI. Podman v3's remote socket
  transport could keep attached batch and TTY clients open after a workload
  exited, producing false timeouts and correctly blocking alpha.11 before any
  artifacts were built.
- Real-runtime batch failures now include their bounded captured stderr in the
  integration assertion, making future release-gate failures actionable without
  weakening the gate.

## Native packages

The release workflow stages a Linux x86_64 AppImage for direct distribution and
a Linux x86_64 DEB for managed distribution. macOS, Windows, Linux arm64, RPM,
Flatpak, Snap, Homebrew, and browser extensions are not included in this alpha.

The packaged desktop includes the Chromium runtime required for rendered URL
sources. Docker or Podman is required for terminal, automation, VPN, and isolated
debugger features. OpenVPN support requires the Nebula container image shipped
for this release.

## Deliberate boundaries and alpha limitations

- This is a prerelease and may contain compatibility defects or incomplete UX.
- VPN routing applies to selected container workloads, not to the Nebula host or
  the browser device used to operate Nebula remotely.
- Uploaded VPN profiles remain untrusted input; unsupported or unsafe directives
  fail closed.
- The protected release workflow does not build a macOS package.
- Physical iPhone Safari, physical macOS remote-Core, and provider-diverse VPN
  workflows remain manual verification gates.

## After installation

Launch the Linux desktop with `nebula`, then verify the bundled Core:

```console
nebula-core doctor --json
```

To verify a selected VPN from a Nebula container terminal, run:

```console
curl -4 https://api.ipify.org && echo
```

Compare that result with the same command on the Nebula host. Report defects with
the exact version, platform, failed action, correlation ID, and a reviewed
Diagnostics support bundle.
