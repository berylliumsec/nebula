# Getting help with Nebula

## Start with the documentation

- [README](README.md): supported preview installers and source setup
- [Nebula 3 guide](docs/NEBULA3.md): product usage and configuration
- [Local diagnostics](docs/NEBULA3_DIAGNOSTICS.md): troubleshooting
- [Migration guide](docs/MIGRATING-2-TO-3.md): moving from Nebula 2
- [Published releases](https://github.com/berylliumsec/nebula/releases): available
  builds and their release notes

The current preview installer matrix is documented in the README. A feature or
release note in a source checkout does not establish that a build is published.

## Choose a channel

- **Setup, usage, and general questions:** search or start a
  [Discussion](https://github.com/berylliumsec/nebula/discussions).
- **Reproducible bugs, specific feature requests, and documentation corrections:**
  search [existing issues](https://github.com/berylliumsec/nebula/issues), then
  [choose an issue template](https://github.com/berylliumsec/nebula/issues/new/choose).
- **Vulnerabilities in Nebula:** follow [Security](SECURITY.md) and report privately.
- **Community conduct concerns:** use the reporting instructions in the
  [Code of Conduct](CODE_OF_CONDUCT.md).

Include your Nebula version or source commit, installation method, operating
system and architecture, and the affected surface (desktop, browser, or Core).
For browser problems, distinguish the browser device from the Nebula host and
include the browser name and version. Describe what you expected, what happened,
and the smallest safe example that shows the problem.

## Keep shared information safe

Issues and Discussions are public. Share only the relevant, sanitized portion of
an error or log. Remove API keys, passwords, tokens, cookies, private keys,
personal data, customer details, target identifiers, and private paths from text
and screenshots. Use synthetic examples rather than real engagement evidence.
Do not upload a complete project, database, diagnostic bundle, or report without
reviewing everything it contains.

Community help depends on contributor availability. This guide does not promise
a response or resolution time.
