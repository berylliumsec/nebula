Nebula is a cybersecurity harness.

Built around the operator, Nebula supports manual testing in the browser and Kali terminal or autonomous coding and testing by agents in Assistant or Missions. Set project scope, tools, and approvals; carry evidence into findings and reports.

Install Linux preview Read the guide

Linux x86_64 preview. Host mode runs without Docker or Podman; the Kali terminal and Docker mode require a container runtime.

Run agents autonomously

Bring Codex or Grok harnesses, or run Nebula's agent with Anthropic's Claude, OpenRouter, or local models. Inspect reported token and cache use.

Choose the boundaries

Set scope, tools, approvals, and Host or Docker mode. Route container traffic through an OpenVPN profile when needed.

Keep the evidence

Preserve output, link it to findings, and produce reports in the same project.

Mercury is optional. When Nebula Core and its agent processes are enrolled under Mercury, Mercury can add a separate runtime policy layer.

Use Nebula only on systems you own or are authorized to test.
